# Phase 3 implementation plan

[Requirements](requirements.md) · [Validation](validation.md)

1. **Prove the new model through the public build.** Document the XML v3 contract: networks, Case Input bindings, probability tables, decision references, applicability, numeric partitions, and sampling. Author matching synthetic Source Material, XML, inventory, and independent verification cases. Begin with a buildable decision whose selected action posterior changes with observed evidence through a latent node. Validate before generating browser data. Keep both existing schema versions and their fixtures as regression coverage.
2. **Share multi-input evaluation and verification.** Extend the evaluator seam to accept Case Inputs keyed by ID, evaluate applicability, and infer the selected action posterior. Use the same evaluation for build-time verification and the original browser result. Expand v3 cases and coverage checks for independent multi-input outcomes and each relevant threshold while preserving version-specific legacy rules. Confirm failure isolation, partial labeling, separate reports, and safe publication.
3. **Deliver the controlled original case and sandbox.** Keep original values reusable by input ID. Show only the chosen decision's Case Inputs and provide an isolated editable copy with its own result and reset. Check joint edits, invalid and missing values, condition and citation display, decision switches, and the difference between copying and modifying the original.
4. **Deliver the tornado chart and unavailable states.** Derive the sweep from the original case and each input's declared test domain; evaluate one substitution at a time and render comparable ranges, exact samples and units, and reasons for excluded states. Verify differing spans, equal scores, missing metadata, and unscoreable baselines without disabling the sandbox.
5. **Verify portability and close the phase.** Run the full [merge checklist](validation.md), including the existing fixtures and the new model through the public build and relocated offline app. Extend the [v3 model-author contract](xml-v3.md) for the full fixture, and record actual verification results separately from the planned checks. No later-phase work is needed for this exit.
