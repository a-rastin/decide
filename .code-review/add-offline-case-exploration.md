## Standards

### Documented breaches

1. **High — Applicability can freeze the app on a blank case.** [The build](../src/read-model.ts#L287-L312) caps Bayesian assignments but not [the separate search for which missing inputs affect applicability](../src/model.ts#L112-L151). That search runs synchronously when the app opens. In a synthetic evaluator check, four numeric inputs with five thresholds each took 12.7 seconds despite fitting well below the network cap. [Phase 3 requirements](../dev-docs/specs/2026-11-22-add-offline-case-exploration/requirements.md#L43) require inference size limits to be documented and enforced at build time so unsupported models do not first fail in the browser. Bound the applicability search or simplify predicates before enumerating assignments.
2. **Medium — Rounding changes chart semantics, not just presentation.** The rounded [`spanRank`](../src/app/sensitivity-bars.tsx#L34-L43) controls both sort order and the [“No modeled change” label](../src/app/sensitivity-bars.tsx#L73-L80). Scores of `0` and `2.220446049250313e-16` produce a rank of zero. The [chart requirements](../dev-docs/specs/2026-11-22-add-offline-case-exploration/requirements.md#L49-L50) require descending score-span order and reserve the unchanged label for equal scores. Distinguish nonzero spans below display precision from unchanged scores.

### Code smells (judgment calls)

3. **Low — Possible Repeated Switches.** The [case result](../src/app/case.tsx#L92-L124), [Sensitivity Bars](../src/app/sensitivity-bars.tsx#L4-L13), and [sandbox](../src/app/what-if-sandbox.tsx#L7-L14) each classify `result.status === "missing"` and other unscored outcomes. Consider sharing the classification while keeping view-specific wording.
4. **Low — Possible Duplicated Code.** The [v3](../src/model.ts#L61-L63) and [legacy](../src/model.ts#L297-L299) comparisons define parallel tables: `{ lt: order < 0, … }` and `{ lt: comparison < 0, … }`. Share the comparator while preserving the legacy XML operator allowlist.
5. **Low — Possible Speculative Generality.** The evaluator allows [`states?: string[]`](../src/model.ts#L30-L32) and falls back to [`input.states?.[index] ?? value`](../src/model.ts#L65-L69), but the [XML v3 contract](../dev-docs/specs/2026-11-22-add-offline-case-exploration/xml-v3.md#L81-L84) requires explicit state mappings. Require an explicit mapping in the evaluator type and declare identity mappings in tests.

## Spec

1. **High — Verified models can freeze case exploration.** [Requirements § Model and evaluation](../dev-docs/specs/2026-11-22-add-offline-case-exploration/requirements.md#L43): “Document and validate any inference size limits at build time so that the browser is not the first place an unsupported network fails.” [Build validation](../src/read-model.ts#L311-L313) caps Bayesian assignments, but [applicability](../src/model.ts#L125-L148) has its own unbounded search that runs [during rendering](../src/app/main.tsx#L16-L17). A synthetic 4,096-assignment model passed all five authored verification cases, but evaluating it with the gate selected and ten readings blank took 35.6 seconds.
2. **Medium — An unmet condition can hide an invalid input.** [Requirements § Model and evaluation](../dev-docs/specs/2026-11-22-add-offline-case-exploration/requirements.md#L42): “Mark invalid entries distinctly and do not coerce them to unknown or to a number.” For `all(marker = A, reading > 0)`, marker `B` and reading `abc` yield only `unmet`: [applicability](../src/model.ts#L100-L111) short-circuits before reporting the invalid operand, and [the numeric control](../src/app/case.tsx#L49-L50) exposes `aria-invalid=false`. The condition can remain unmet without hiding the malformed entry.
3. **Medium — A positive score can become zero.** [Requirements § Model and evaluation](../dev-docs/specs/2026-11-22-add-offline-case-exploration/requirements.md#L43): “For applicable guidance, compute the action posterior from the decision's declared evidence and use its complement as the Do-Not-Consider Score for the same option.” For an accepted action row `1 1e-100`, the non-selected posterior is approximately `1e-100` and is representable. The [selected posterior](../src/model.ts#L203) rounds to `1`, so [subtraction](../src/model.ts#L168-L171) returns `0`.
4. **Low — Sensitivity Bars report unequal scores as unchanged.** [Requirements § Tornado chart](../dev-docs/specs/2026-11-22-add-offline-case-exploration/requirements.md#L50): “If equal scores are genuinely comparable, label them as no modeled change and show the common score; do not fabricate a span.” Scores of `0.5` and `0.49999999999999967` produce a zero [ranking key](../src/app/sensitivity-bars.tsx#L41-L43), so the [chart](../src/app/sensitivity-bars.tsx#L73-L80) says “No modeled change.”

No clear scope creep found.

**Summary:** Standards: 5 findings (2 documented breaches, 3 smells), led by the unbounded applicability search. Spec: 4 findings, led by verified models freezing case exploration.
